titulo: Chave de API deixa de valer quando quem a criou sai da empresa
---
Uma chave de API (Configurações › Chaves de API) agora só vale enquanto a pessoa que a criou continua na organização, com um papel pelo menos igual ao que a chave concede. Quem sai da empresa, ou é rebaixado, não segue operando o CRM por uma chave antiga; a integração recebe a recusa com a instrução de pedir uma chave nova a um administrador. Ao criar uma chave, só os escopos oferecidos na tela são aceitos, e a chave não pode conceder papel maior que o de quem a cria. A lista de chaves deixou de mostrar as credenciais internas de cinco minutos que o agente de IA usa a cada atendimento, e a limpeza diária passou a apagar as vencidas que nenhum registro de auditoria cita.
